⚙️ Backend API (app/)

FastAPI con routers para auth, modelos, watermark IDs, movimientos y reports. SQLAlchemy async. Rate limiting con slowapi.

Python 3.12 FastAPI SQLAlchemy Pydantic

👁️ Watcher Daemon (watcher/)

Demonio autónomo que orquesta el escaneo periódico de leaks en 6 fuentes externas + simulación de movimientos de trading.

httpx asyncio Alpaca Binance

🌐 Frontend SPA (public/)

SPA vanilla JS con hash router, 10 páginas, Tailwind CSS CDN. Diseño dark-tech con glassmorphism.

Vanilla JS Tailwind Vite

🐘 Base de Datos

PostgreSQL 16 en producción (async via asyncpg), SQLite en desarrollo (aiosqlite). Migraciones con Alembic.

PostgreSQL Alembic SQLite

☁️ Cloud & Deploy

Cloud Run + Firebase Hosting + Cloud SQL. CI/CD via Cloud Build. Docker multi-stage. Secrets via Secret Manager.

Cloud Run Firebase Docker

🔗 Servicios Externos

Motores de búsqueda y APIs de terceros para detección de fugas: SERPER, Brave, GitHub, HuggingFace, PSBDMP.

SERPER Brave GitHub HuggingFace

5. Endpoints de la API

MétodoRutaAuthDescripción
POST/auth/register❌Registrar compañía → recibe api_key (one-time)
POST/models✅Registrar nuevo modelo
GET/models✅Listar modelos de la compañía
POST/ids✅Generar nuevo watermark ID (QM-XXXX-XXXX)
GET/ids✅Listar IDs con filtros (?model_id=&status=)
GET/ids/by-serial/{serial_code}❌Buscar ID por serial code (público)
PATCH/ids/{id}✅Actualizar estado (revocar)
POST/ids/{id}/movements✅Registrar movimiento del modelo
GET/ids/{id}/movements✅Listar movimientos de un ID
POST/ids/{id}/report✅Reportar uso sospechoso → genera PDF certificado
GET/reports/{id}❌Detalle del reporte (incluye certificate_url)
GET/reports❌Listar reportes
GET/health❌Health check
GET/stats❌Estadísticas agregadas
